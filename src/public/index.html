📖 Quick Start Guide

1. Authentication

Include your API key in every request using the x-api-key header or apiKey query parameter.

// Using fetch with header fetch('https://your-api.onrender.com/api/weather/current?city=London', { headers: { 'x-api-key': 'your-api-key-here' } }) .then(response => response.json()) .then(data => console.log(data));

2. Weather API Example

// Get current weather GET /api/weather/current?city=London&apiKey=your-api-key // Response { "success": true, "data": { "city": "London", "temperature": 18, "condition": "Cloudy", "humidity": 65, "windSpeed": 12 } }

3. QR Code API Example

// Generate QR code POST /api/qrcode/generate { "text": "https://ntandomods.com", "format": "png", "size": 300 } // Returns base64 encoded image

4. Text Analysis API Example

// Analyze text sentiment POST /api/text-analysis/analyze { "text": "I love this API! It's amazing and super easy to use." } // Returns sentiment, word count, and statistics

5. Currency Converter Example

// Convert currency GET /api/currency/convert?from=USD&to=EUR&amount=100 // Response { "success": true, "data": { "from": { "currency": "USD", "amount": 100 }, "to": { "currency": "EUR", "amount": 92 }, "rate": 0.92 } }

6. Image Processing Example

// Apply filter to image POST /api/image/filter { "imageUrl": "https://example.com/image.jpg", "filter": "grayscale" } // Returns processed image as base64

Error Handling

All errors follow a consistent format:

{ "error": "Error Type", "message": "Detailed error message", "status": 400 }

Rate Limits

Rate limit information is included in response headers:

X-RateLimit-Limit: 100 X-RateLimit-Remaining: 87 X-RateLimit-Reset: 1698765432
